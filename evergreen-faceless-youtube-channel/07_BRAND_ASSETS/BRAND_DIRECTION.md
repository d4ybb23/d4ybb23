# Brand Direction — The Profit Map

**Purpose:** Make the channel recognizable without making every episode look like it was processed through the same financial aquarium.  
**Visual principle:** Documentary clarity first; decorative polish second.

## 1. Identity System

| Element | Decision | Production instruction |
| --- | --- | --- |
| Brand name | **The Profit Map** | Use title case in public text. Avoid attaching “TV,” “Official,” or “Media” unless name clearance requires a variation. |
| Primary message | The hidden business logic behind the things you use. | Use on banner and trailer, not necessarily every thumbnail. |
| Personality | Exacting, curious, composed, lightly cinematic | Graphics should feel like an elegant briefing, not a trading terminal with a caffeine problem. |
| Visual metaphor | Map / route / system diagram | Use paths, grids, flows, labels, and relationships—not literal treasure maps. |
| Faces | Optional editorial context, never a host requirement | Use only where story-relevant and rights-cleared. |

## 2. Color Palette

| Role | Color name | Hex | Use |
| --- | --- | --- | --- |
| Base | Midnight Ledger | `#0D1B2A` | Main background, navy overlays, main title card. |
| Surface | Blueprint Slate | `#1B263B` | Secondary surfaces, diagram panels. |
| Light | Paper Signal | `#F7F3E8` | Primary type, contrast lines, light cards. |
| Accent 1 | Ledger Gold | `#F4B942` | Key number, route, or business mechanism. |
| Accent 2 | Signal Teal | `#3BC1C6` | Systems, technology, logistics, neutral data relationships. |
| Warning / tension | Margin Red | `#D65A50` | Risk, loss, constraint, trade-off; use sparingly. |

## 3. Type Direction

| Use | Direction | Practical fallback |
| --- | --- | --- |
| Display / thumbnail | Condensed, authoritative sans-serif | Use a bold condensed licensed font or platform-safe equivalent. |
| Body / captions | Clear humanist sans-serif | Use a legible standard sans-serif. |
| Data labels | Neutral mono or narrow sans-serif, sparingly | Use only for numbers, labels, and diagrams. |

Never let type styling obscure the noun or number that carries the idea. If the video is about membership fees, the audience needs to read “MEMBERSHIP,” not admire the kerning until the episode ends.

## 4. Thumbnail System

| Component | Rule |
| --- | --- |
| Composition | One subject and one visual question. Keep 25–35% open/quiet area for focal contrast. |
| Subject | A logo, object, map, receipt, packaging object, storefront, or clean original diagram. |
| Text | Zero to four words, placed as a visual counterpoint rather than a title duplicate. |
| Contrast | Darker field + one high-value light/bright object; test at phone size. |
| Chart use | One single number or flow only; no dense dashboards. |
| Treatment | Light grain, high contrast, honest scale. No fake red-circle scandal grammar. |
| Consistency | Use palette and type system; vary composition and visual metaphor by topic. |

### First three thumbnail directions

| Pilot | Title | Concept | On-image text |
| --- | --- | --- | --- |
| TPM-001 | Why Costco Actually Makes Money by Selling So Little | Giant membership card or receipt on a warehouse shelf; a clean gold flow line moves from fee to profit bar. | **THE REAL PROFIT** |
| TPM-002 | How IKEA Turned a Flat Box Into a Global Moat | A single flat-pack carton transforms into a container/map route; no crowded store collage. | **ONE BOX. BILLIONS.** |
| TPM-003 | Why McDonald’s Owns So Much of the System Behind the Sign | Golden arch/store silhouette over a simplified land/building/franchisee flow. Avoid the unsupported “largest landlord” meme. | **WHO OWNS WHAT?** |

## 5. On-Screen Motion Language

| Narrative job | Motion treatment |
| --- | --- |
| Introduce a mechanism | Draw a route or node sequence from left to right; narration drives the reveal. |
| Compare two choices | Two-panel separation with a single changing variable. |
| Show time | Horizontal timeline with only narrative-relevant dates. |
| Show scale | One anchored object; animate scale change with a labeled source. |
| Establish place | Map zoom or simple location pin; avoid noisy globe animation. |
| Signal trade-off | Use split path, counterweight, or shrinking margin space—not fireworks. |

| Asset | Minimum specification | Status |
| --- | --- | --- |
| Circular avatar | Simple `TPM` monogram or abstract route mark, legible at 98px. | Brief ready; requires design execution. |
| Banner | 2560 × 1440 px; keep core copy in YouTube’s central safe region. | Brief ready; requires design execution. |
| Thumbnail base file | 1280 × 720 px with editable color, type, and safe-area guides. | Brief ready; requires design execution. |
| Intro/outro stinger | 1–2 seconds maximum; optional. | Do not make this a launch dependency. |
| Diagram kit | Arrow, node, card, label, timeline, map-pin, and comparison components. | Build before Pilot 01 edit. |

## 7. Licensing Note

Do not use the image-search references collected during planning as production assets unless their exact license and intended use are independently verified. The visual system is built to reduce this dependency: the core differentiator is original layout, diagrams, and editing, not borrowed pictures wearing expensive color grading.
